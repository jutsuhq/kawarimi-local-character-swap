# Kawarimi: эпики и задачи

Всё, что осталось после фаз 0 и 1 ([PLAN.md](PLAN.md), [edgetam-onnx](https://github.com/jutsuhq/edgetam-onnx/blob/main/docs/PARITY.md)), разбито по этапам. Этап
открывает следующий: внутри этапа эпики идут по порядку, задачи без зависимостей можно делать параллельно.
Задача — 1–3 дня работы и проверяемый критерий «готово».

Номера `K-NN` сквозные. «Зависит» — задачи, без которых эта не начнётся.

Всё заведено в GitHub issues: эпик `EN` — issue `#N+1` (E0 — #1, E13 — #14), задача `K-NN` — issue `#NN+14`
(K-01 — #15, K-62 — #76). Метки `stage 1.5` … `stage 7`, `later`, `epic`, `task`.

## Риски

- **8 GB VRAM.** На RTX 3070 Wan 2.2 Animate 14B, скорее всего, не поместится. Рендер придётся проверять на
  карте побольше или на удалённом ComfyUI (K-23, K-28).
- **Экспорт EdgeTAM** один и без исходников; если box-промпт не работает (K-12), понадобится свой экспорт.
- **Пины FFmpeg (BtbN)** удаляются через какое-то время; нужен свой зеркальный релиз (K-04).
